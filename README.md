## About This Website

A responsive, static portfolio built with **React, TypeScript, and Vite**, with dark/light mode, scroll animations, and a downloadable resume. It has no backend or database and is hosted on **GitHub Pages**.

### Project Structure

```
├── public/
│   └── resume.pdf            # Downloadable resume
├── src/
│   ├── data/profile.ts       # All site content (single source of truth)
│   ├── components/           # Section components
│   ├── hooks/                # Theme and scroll-reveal hooks
│   └── index.css             # Design tokens and styles
├── .github/workflows/        # GitHub Pages deployment
└── vite.config.ts
```

### Run Locally

```bash
npm install
npm run dev
```

Then open the printed local URL (usually `http://localhost:5173`).

### Customize

- Edit `src/data/profile.ts` to update experience, projects, skills, and links.
- Replace `public/resume.pdf` to update the downloadable resume.
- Set `base` in `vite.config.ts` to your repository name (for example `'/my-repo/'`), or `'/'` if the repo is named `<username>.github.io`.

### Deploy to GitHub Pages

1. Push the project to GitHub.
2. Go to **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Push to `main`. The workflow in `.github/workflows/deploy.yml` builds and publishes the site.
